# Çamaşır Makinesi Opera Bestecisi

> Dünyanın ilk (ve muhtemelen son) **Endüstriyel Çamaşır Dramaturjisi** motoru.

Bu yazılım, ev tipi çamaşır makinenizin her programını Verdi ruhuyla yeniden yazar.  
Pamuklu 40°C artık sıradan bir döngü değildir. O bir **arya**dır.

## Neden var?

Çünkü bir makine 1200 devirle dönerken sessiz kalmak kültürel bir suçtur.  
ISO 9001 ruhuyla, her sıkma turu için libretto üretiriz. Patent yok, vicdan var.

## Kurulum

```bash
python3 besteci.py --program pamuklu --derece 40 --sikma 1200
```

## Desteklenen programlar

- pamuklu
- sentetik
- hassas
- hizli
- yun
- durulama
- sikma
- eko

## Örnek çıktı

```
=== ARIA DEL BUCATO N.40 ===
(soprano + tamburlu koro)

Ey tambur, ey dönen kader!
Köpükler arasında kaybolan çoraplar için ağla.
1200 devirde yüksel, ey tenor motor!
```

## Sorumluluk reddi

Bu yazılım çamaşırınızı temizlemez. Sadece duygusal olarak yükselterek kirini unutturur.  
Makine garantinizi bozmaz çünkü hiçbir GPIO pinine dokunmaz. Sadece hayal gücüne dokunur.
